eFootball Scraper API

API nội bộ để điều khiển scraper và truy vấn dữ liệu cầu thủ eFootball đã cào. Tất cả data được lấy từ eFootbase API và lưu vào MongoDB riêng.

Base URL: http://localhost:4000

Database: efootball_scraper (MongoDB)

Tổng cầu thủ: ~43,000 (432 pages × 100)

Nguồn dữ liệu gốc

Data được cào từ eFootbase API — API nội bộ của ứng dụng eFootbase (Dart/Flutter). Không có tài liệu chính thức.

Scraper Control

Bắt đầu cào

POST /api/start Bắt đầu scraper

Body (JSON):

Field Type Mô tả
startPage number Trang bắt đầu optional
endPage number Trang kết thúc optional
limit number Cầu thủ/trang (max 100) optional
skipImages boolean Bỏ qua tải ảnh optional

Dừng scraper

POST /api/stop Dừng scraper đang chạy

Không cần body. Scraper sẽ dừng sau khi xong cầu thủ hiện tại và lưu progress.

Tiếp tục từ lần trước

POST /api/resume

Tiếp tục cào từ page cuối đã hoàn thành.

Cào lại page lỗi

POST /api/retry

Cào lại các page bị lỗi từ lần chạy trước.

Trạng thái hiện tại

GET /api/state

Trả về toàn bộ trạng thái scraper: status, page hiện tại, counters, recent players...

Data API

Danh sách cầu thủ

GET /api/players Phân trang + tìm kiếm
Param Type Mô tả Default
page number Trang 1
limit number Số kết quả/trang 20
search string Tìm theo tên (regex) —
sort string Sắp xếp theo field overall.max

Chi tiết cầu thủ

GET /api/players/:efhubId

Trả về toàn bộ thông tin 1 cầu thủ theo efhubId.

Thống kê DB

GET /api/stats

Tổng số cầu thủ, OVR trung bình, OVR cao nhất.

Real-time SSE

GET /events Server-Sent Events

Stream real-time trạng thái scraper. Dùng EventSource trong JavaScript: 

const es = new EventSource('/events');
es.onmessage = (event) => {
  const state = JSON.parse(event.data);
  console.log(state.currentPlayer, state.totalPlayers);
};
